# CoastAI deployment checklist

- [ ] Confirm the contact email address works.
- [ ] Install dependencies and run `npm run build`.
- [ ] Preview the website on desktop and mobile.
- [ ] Import the GitHub repository into Vercel.
- [ ] Add a custom domain after deployment if available.
- [ ] Before advertising automation services, configure and test each integration separately.
- [ ] Add privacy, data-handling, and customer consent information before collecting personal data.
